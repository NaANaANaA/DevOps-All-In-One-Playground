# dhomane-devops-templates

This folder is inspired by the MIT-licensed [`dhomane/DevOps-Templates`](https://github.com/dhomane/DevOps-Templates) project structure. The files here are original starter assets for reuse in other repositories.

## Included assets

- `.github/workflows/ci-template.yml` for validation and image builds
- `.github/workflows/deploy-template.yml` as a reusable deployment workflow
- `terraform/modules/app-starter/` for provider-neutral Terraform scaffolding
- `ansible/` for local prerequisite checks and Kubernetes deployment
